# Security Policy

## Supported Versions

Pattelock is currently in its early stages. We recommend using the latest version of the application.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.0| :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Pattelock installs a system-wide keyboard hook, so we take security reports seriously.

If you discover a security vulnerability in Pattelock, please DO NOT report it as a public GitHub issue. Instead, report it privately through GitHub: open the [Security tab](https://github.com/HugoSohm/pattelock/security) of the repository and click **Report a vulnerability**.

Please include:
1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. Your operating system (and on Linux, X11 or Wayland).
4. Your suggested fix (if any).

We will verify and address the issue as soon as possible.
