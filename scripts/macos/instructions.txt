--- INSTRUCTIONS D'INSTALLATION / INSTALLATION INSTRUCTIONS ---

FRANÇAIS :
1. Glissez Pattelock.app dans votre dossier Applications.
2. Ouvrez un terminal et lancez la commande suivante :
   sudo xattr -c /Applications/Pattelock.app
3. Au premier lancement, autorisez Pattelock dans
   Réglages Système > Confidentialité et sécurité > Accessibilité
   (nécessaire pour bloquer les touches).
   Après chaque mise à jour, macOS peut redemander cette autorisation :
   retirez Pattelock de la liste puis ajoutez-le de nouveau.

ENGLISH:
1. Drag Pattelock.app into your Applications folder.
2. Open a terminal and run the following command:
   sudo xattr -c /Applications/Pattelock.app
3. On first launch, allow Pattelock in
   System Settings > Privacy & Security > Accessibility
   (required to block keys).
   After each update, macOS may ask for this permission again:
   remove Pattelock from the list, then add it back.
